# Публикация на GitHub Pages

Проект уже использует только относительные пути (`./...`), поэтому подходит для GitHub Pages без сборщика.

## Вариант через интерфейс GitHub

1. Создайте новый репозиторий, например `algebra8-course`.
2. Загрузите **содержимое этой папки** в корень репозитория.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. Нажмите `Save`.

Через несколько минут GitHub покажет адрес сайта вида:
`https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/algebra8-course/`

## Обновление курса

При следующей версии достаточно заменить файлы в репозитории.  
Service Worker использует версионный cache key, поэтому после обновления новая версия постепенно заменит старый офлайн-кэш.

## Проверка перед публикацией

- `index.html` находится в корне;
- `manifest.json` доступен;
- папка `assets` загружена;
- `.nojekyll` оставлен в корне;
- сайт открывается по HTTPS — это необходимо для установки PWA.
