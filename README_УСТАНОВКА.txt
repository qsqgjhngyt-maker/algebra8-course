«ПРИВЕТ, КИТСУНЕ»

Wake-фраза работает ТОЛЬКО пока приложение открыто и видно на экране.

Для нее НЕ используется Cloud Speech / Web Speech API.
Сырой звук не отправляется в Cloud.

Чтобы не держать тяжелый Whisper постоянно включенным, beta.3.8 использует
легкий персональный локальный акустический шаблон.

При первом включении:
- нажать «Настроить фразу»;
- три раза произнести «Привет, Китсуне»;
- шаблоны сохраняются только в localStorage этого устройства.

После срабатывания:
локальный Wake Engine
→ Kitsune появляется
→ «Я здесь. Слушаю тебя.»
→ существующий локальный Whisper слушает настоящий вопрос
→ существующий Router / Math / Tutor / Qwen
→ существующий Piper Irina / voice fallback.

Wake listener отключается:
- когда открывается голосовой диалог;
- пока Kitsune говорит;
- когда вкладка/PWA уходит в фон;
- при выключении настройки.

При возвращении в приложение он запускается снова, если функция включена.

ВАЖНО

Это персонализированный wake-template, а не универсальная языковая модель.
Поэтому на каждом устройстве желательно один раз произнести фразу 3 раза.
Это одновременно делает механизм заметно легче и полностью локальным.

ПРОВЕРКА

A. Персонаж
1. Открыть приложение.
2. Нажать «−» около Kitsune.
3. Перетащить свернутую Kitsune вверх/вниз и к другому краю.
4. Перезапустить PWA — положение должно сохраниться.
5. Тапнуть свернутую Kitsune — полный анимированный персонаж возвращается.

B. Wake phrase
1. Kitsune → настройки.
2. Включить «Привет, Китсуне».
3. Первый раз — произнести фразу 3 раза для локальной настройки.
4. Свернуть персонажа.
5. Сказать «Привет, Китсуне».
6. Kitsune должна появиться, открыть голосовой диалог и затем включить Whisper
   для следующего вопроса.

C. Приватность
- при скрытии приложения микрофон wake режима должен выключиться;
- после возврата ожидание восстанавливается;
- никакого нового сетевого endpoint/Cloudflare запроса для wake phrase нет.

D. Регрессия
- обычный текстовый чат работает;
- тематическая память beta.3.7.2 работает;
- Math Engine/Tutor работают;
- Owner/Admin работают;
- Piper Irina/Whisper/hands-free работают как раньше.

Cloud Brain не изменялись.
