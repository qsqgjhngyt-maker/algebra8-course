Kitsune v2.3.0-beta.3.7.1 — исправление тематической памяти

ПРОБЛЕМА

В beta.3.7 тематическая память добавлялась прямо к пользовательскому message
до вызова Router. Поэтому текст старых реплик мог влиять на классификацию
нового вопроса.

Пример:
1. «Объясни дискриминант»
2. «А почему он бывает отрицательным?»

В памяти уже находилась служебная строка `Kitsune: ...`.
Старый локальный классификатор видел слово `Kitsune` и мог принять весь
составной текст за greeting, отвечая «Я здесь 🦊 ...».

ИСПРАВЛЕНИЕ

В beta.3.7.1:
- Router всегда получает ТОЛЬКО настоящий текущий вопрос пользователя;
- Safety / Math Engine / Tutor / Cloud выбираются по этому чистому вопросу;
- тематическая память подмешивается только ПОСЛЕ выбора маршрута;
- память перехватывает только уже выбранный `cloudRequest("chat", ...)`;
- Math Engine, Tutor и локальный fallback памятью не загрязняются;
- TTS/voice-design запросы не изменяются;
- служебная метка `Kitsune:` заменена на нейтральную `Ассистент:`.

Cloudflare Worker, D1, Owner/Admin, Whisper, Piper Irina и chat firewall
в этом патче НЕ меняются.

ЧТО ЗАМЕНИТЬ В GITHUB

В корне:
- voice-conversation-v237.js
- index.html
- sw.js
- version.json

Больше ничего менять не нужно.

ПРОВЕРКА

Сценарий 1 — память темы:
- «Объясни дискриминант»
- «А почему он бывает отрицательным?»
- «А если он равен нулю?»

Ожидается: три последовательных ответа по одной теме. Реплика «Я здесь 🦊…»
не должна появляться, если пользователь сам не позвал Kitsune/не поздоровался.

Сценарий 2 — старые слова не влияют на новый route:
Предыдущая память может содержать:
- «Kitsune»
- «привет»
- «реши»
- «ответ»
- математические выражения

Затем задать обычный вопрос:
- «А почему так происходит?»

Route должен определяться только по этой последней фразе.

Сценарий 3 — Math/Tutor:
- конкретное вычисление;
- явный вопрос по открытому заданию.

Они должны, как и раньше, идти локально.

КОММИТ

Название:
v2.3.0-beta.3.7.1 — Исправлена тематическая память диалога

Описание:
Исправлено влияние предыдущих реплик на классификацию нового вопроса.
Router теперь получает только текущий текст пользователя, а компактная
тематическая память добавляется исключительно после выбора Cloud-маршрута.
Локальные Math Engine и Tutor не получают служебную память.
