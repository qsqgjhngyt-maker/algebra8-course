Kitsune v2.3.0-beta.3.7 — Живой голосовой диалог

ЧТО ДОБАВЛЕНО

1. Тематическая память
- Kitsune продолжает одну тему: «а почему?», «а если так?», «что дальше?» понимаются
  в контексте предыдущих реплик.
- Память разделена по урокам/контекстам.
- Есть кнопка «Новая тема».
- Полная история остаётся локально.
- Для обычного Cloud Brain может добавляться только короткая безопасная выдержка
  последних реплик (до ~920 символов). Email, телефоны, адресные/личные фразы и
  другие потенциально чувствительные фрагменты в эту выдержку не включаются.
- Точные математические запросы и помощь по текущему заданию не получают
  облачную память: они остаются на локальном Math/Tutor маршруте.

2. Голосовой диалог
- микрофон → локальный Whisper;
- ответ → Kitsune Router;
- озвучка → локальный Piper Irina при готовой модели;
- если Irina не готова/не запустилась, сохраняется существующий fallback;
- «Разговор без рук»: после озвучки Kitsune снова включает слушание;
- нажатие на микрофон во время речи перебивает Kitsune.

3. Приватность
- сырой звук не отправляется в Cloud;
- полный журнал разговора не отправляется в Cloud;
- тематическая память хранится в localStorage этого устройства;
- существующий режим Child Safety и beta.3.6.2 firewall сохранены.

ПЕРВЫЙ ЗАПУСК

1. Открыть настройки Kitsune / Voice Dialogue.
2. Whisper должен остаться подготовленным как раньше.
3. В блоке «Живой голосовой диалог» нажать «Подготовить Irina».
4. Разрешить браузеру воспроизведение/микрофон при запросе.
5. Открыть «Поговорить».
6. Включить «🎧 Разговор без рук» при желании.

ПРОВЕРКА ПАМЯТИ

Сказать:
- «Объясни, что такое дискриминант».
- После ответа: «А почему он может быть отрицательным?»
- После ответа: «А если он равен нулю?»

Kitsune должна продолжить ту же тему без повторного полного вопроса.

ПРОВЕРКА РАЗДЕЛЕНИЯ ТЕМ

- Нажать «Новая тема».
- Спросить про линейную функцию.
Предыдущая тема дискриминанта не должна вмешиваться.

НАЗВАНИЕ КОММИТА
v2.3.0-beta.3.7 — Добавлен живой голосовой диалог Kitsune

ОПИСАНИЕ
Добавлен непрерывный голосовой диалог с локальным Whisper и Piper Irina, режим разговора без рук и возможность перебить озвучку микрофоном. Реализована локальная тематическая память для последовательных вопросов и ответов с безопасной компактной передачей контекста в Cloud Brain только для обычного диалога. Полная история и сырой звук остаются на устройстве.
