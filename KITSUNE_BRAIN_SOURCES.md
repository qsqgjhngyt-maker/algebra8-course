# Kitsune Brain — components / license notes

Kitsune is an original SVG fox character created specifically for this course.

Local language layer:
- WebLLM: `@mlc-ai/web-llm@0.2.84`
- Model ID: `Qwen2.5-0.5B-Instruct-q4f16_1-MLC`
- Upstream Qwen2.5-0.5B-Instruct license: Apache-2.0
- WebLLM performs in-browser inference using WebGPU.

Important architecture rule:
the language model is not the mathematical source of truth. The deterministic
Math Engine supplies verified facts and the model only rewrites those facts
into short tutoring dialogue.

The course does not imitate a specific copyrighted cartoon character or voice.
