# Neural Voice sources / license notes

This project does not redistribute the neural voice model inside the repository ZIP.

At the user's explicit action, the browser downloads the Piper voice identified as:
`ru_RU-dmitri-medium`.

Sources used by the integration:
- Piper browser runtime: `@mintplex-labs/piper-tts-web` (MIT package).
- Piper Voices repository: `rhasspy/piper-voices`.
- The `ru_RU-dmitri-medium` model card identifies the voice as Russian, medium quality,
  22,050 Hz, and lists its dataset license as CC0.

The course adds its own Web Audio processing and does not attempt to imitate any
specific copyrighted or trademarked character voice.
