# Kitsune Brain v1.8 — запуск на GitHub Pages

## Первый запуск

1. Опубликуйте файлы v1.8.0 на GitHub Pages.
2. Откройте курс в актуальном Chrome/Edge на устройстве с WebGPU.
3. Откройте Kitsune → ⚙.
4. В блоке **🦊 Kitsune Brain** сначала посмотрите проверку устройства.
5. Нажмите **⬇ Подготовить мозг Kitsune**.
6. Дождитесь завершения загрузки/инициализации.
7. Нажмите **💬 Проверить диалог**.
8. Выберите режим **🧠 Brain**.

Большая модель не скачивается автоматически.

## На телефоне

Если WebGPU недоступен или памяти недостаточно, используйте **⚙ Smart Tutor**. Все математические проверки, комиксные подсказки, курс, XP и PWA продолжают работать без LLM.

## Offline

После первой успешной подготовки WebLLM кэширует модель в browser storage. PWA app shell и jsDelivr runtime также кэшируются.

Очистка данных сайта/браузера может удалить локальную модель.
