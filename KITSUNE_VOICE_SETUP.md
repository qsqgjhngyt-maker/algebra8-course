# Kitsune Voice Dialogue v1.9 — первый запуск

1. Опубликуйте v1.9 на GitHub Pages и откройте страницу по HTTPS.
2. Желательно использовать актуальный Google Chrome или Edge.
3. Откройте Kitsune → ⚙.
4. В блоке **Voice Dialogue** нажмите **⬇ Подготовить Whisper**.
5. Дождитесь статуса `Whisper готов`.
6. Нажмите **💬 Поговорить**.
7. Разрешите сайту доступ к микрофону при первом запросе.
8. Нажмите **🎙️ Говорить** и произнесите фразу.
9. Можно закончить вручную кнопкой **■ Стоп** либо просто сделать паузу.
10. После распознавания текст автоматически отправится Kitsune.

## Что работает без Whisper

Текстовый диалог, Smart Tutor, Kitsune Brain, курс и озвучка ответа работают независимо от микрофона.

## Если WebGPU не работает

Voice Dialogue пробует WASM/q8 fallback. Он может быть заметно медленнее, особенно на смартфоне.

## Приватность

Аудио обрабатывается в браузере локальной ASR-моделью. В проекте нет внешнего speech-to-text API и нет API-ключа.

## Важно

Очистка данных сайта может удалить локальный browser cache Whisper и потребовать повторной подготовки модели.
