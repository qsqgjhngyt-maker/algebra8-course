# Neural Voice Kitsune · v1.7

## После публикации на GitHub Pages

1. Откройте курс по HTTPS-ссылке GitHub Pages.
2. Откройте Kitsune → ⚙.
3. В блоке **🎭 Neural Voice Kitsune** оставьте режим **✨ Нейро**.
4. Нажмите **⬇ Скачать голос Kitsune (~63 МБ)**.
5. Дождитесь сообщения **Neural Voice установлен**.
6. Нажмите **▶ Тест нейроголоса**.
7. Подберите **🎬 Мультяшность**. Рекомендуемый старт: 40–55%.

Модель загружается только на конкретное устройство/браузер. На другом телефоне её нужно скачать один раз заново.

Если Neural Voice не запускается, курс автоматически продолжит использовать системную озвучку.

## Технически

- Browser TTS: Piper / ONNX Runtime Web.
- Voice ID: `ru_RU-dmitri-medium`.
- Модель хранится локально в Origin Private File System.
- Runtime-файлы после первого запуска кэшируются Service Worker.
- Внешнего API-ключа и backend нет.
