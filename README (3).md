# Проверки текущего релиза

Требуется Node.js 22+, для браузерных тестов — Playwright 1.62.1 и Chromium. Установите dev-зависимости (`npm install`), затем браузер (`npx playwright install chromium`) либо укажите `CHROME_PATH` на установленный Chrome. При нестандартной установке модуль Playwright можно задать переменной `PLAYWRIGHT_MODULE`.

- `npm test` — синтаксис, текущие regression-проверки, каталог, ссылки, версия, ресурсы, SHA-256 исходного контента.
- `npm run test:browser` — 19 браузерных сценариев, включая офлайн и искусственное безопасное/неудачное обновление.
- `npm run test:voice` — голосовой контроллер с имитациями микрофона/worker; не тест качества речи.
- `npm run test:visual` — desktop/mobile, оформление и снимки.
- `npm run test:broker` — 8 контрактов текущего Worker без внешней генерации.
- `node tests/release/qa-local-server.cjs` — Python-сервер; `PYTHON_PATH` при необходимости задаёт Python 3.
- `npm run test:upgrade` — переход с прежней реально опубликованной версии; задайте `KITSUNE_PREVIOUS_ROOT` на отдельную папку, распакованную из `git archive e69cae4`.

`KITSUNE_QA_ROOT` позволяет проверять другую распакованную копию сборки. По умолчанию проверяется корень этого репозитория. Результаты и снимки создаются рядом с тестами и не коммитятся как runtime. Браузеры запускаются с отдельными временными профилями; обычный пользовательский профиль не используется.

`source-content-sha256.json` фиксирует 88 файлов входного alpha.7 WORK_GRADE8_MODERNIZED. Он подтверждает неизменность этих файлов, но не заменяет математическую экспертизу каждого задания.

Реальные iPhone/Safari, аппаратный микрофон, установка на домашний экран и ответ внешней модели не выдаются за выполненные автоматические тесты.
