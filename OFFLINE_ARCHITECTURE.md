# Офлайн-архитектура beta.3.7

GitHub Pages обслуживает статическую PWA. sw.js кэширует ресурсы из ASSETS; имена кэшей и список ресурсов при очистке сохранены. Модели Whisper/Piper требуют предварительной загрузки и поддержки браузера.

Курс, Math Engine и локальные помощники работают на устройстве. Cloud Qwen, Google-вход и операции доступа через D1 требуют сети. Голосовой цикл и тематическая память реализованы в voice-conversation-v237.js поверх существующих локальных модулей.

Не удалять OPFS, IndexedDB и localStorage при обновлении. Старые версии в URL ресурсов — отдельные ключи кэша. Порядок скриптов в index.html и последний chat firewall сохраняются.

См. [развертывание](docs/DEPLOY.md).
