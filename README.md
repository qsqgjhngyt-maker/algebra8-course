# Алгебра 8 — интерактивный курс

Версия: **v1.2.0**

Что добавлено в этой итерации:
- живой фон из мягких частиц;
- красивые переливы и glow-эффекты;
- переключатель интенсивности эффектов: авто / мягко / выкл;
- адаптация эффектов под мобильные устройства;
- учёт системной настройки `prefers-reduced-motion`;
- сохранён эталонный формат урока;
- рабочее HTML-превью для быстрого утверждения.

## Запуск
Открыть `index.html` или опубликовать проект на GitHub Pages.

## Публикация на GitHub Pages
1. Создать репозиторий.
2. Загрузить все файлы в корень.
3. Открыть `Settings → Pages`.
4. Выбрать `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Сохранить настройки.

## Дальше
Следующий этап — полностью наполнить главу I «Рациональные дроби» и затем перейти к «Квадратным корням».

## v1.0.0 — полный курс

Готовы все 6 глав и 51 тема программы:

1. Рациональные дроби — 9 тем.
2. Квадратные корни — 10 тем.
3. Уравнения и системы — 14 тем.
4. Неравенства — 8 тем.
5. Функции — 5 тем.
6. Степень с целым показателем — 5 тем.

В каждой теме: три уровня объяснения, ключевая схема, «Запомни», «Почему так?», частая ошибка, два пошаговых примера, мини-проверка, четыре самостоятельных задания, задание со звёздочкой и сохранение освоения.

Добавлены интерактивные лаборатории:
- `y = k/x`;
- `y = √x`;
- дискриминант квадратного уравнения;
- числовая прямая для неравенств;
- `y = kx + b`;
- конвертер стандартного вида числа.

Для каждой главы есть диагностика, мини-контрольная и печатная шпаргалка. В конце курса — общая диагностика по всем главам. Тренажёр работает по дробям, корням, квадратным уравнениям, неравенствам и степеням.

Проект остаётся PWA: установка на телефон/ПК, адаптивный интерфейс, офлайн-кэш, локальный прогресс, живой фон и облегчённые эффекты на мобильных устройствах.


## v1.0.0 — полный курс

Полностью реализованы все 6 глав и 51 тема программы:

- глава I «Рациональные дроби» — утверждённая версия;
- глава II «Квадратные корни» — 10 уроков;
- глава III «Уравнения и системы уравнений» — 14 уроков;
- глава IV «Неравенства» — 8 уроков;
- глава V «Функции» — 5 уроков;
- глава VI «Степень с целым показателем» — 5 уроков;
- в каждой новой теме: три уровня объяснения, правила, типичная ошибка, 2 разобранных примера,
  мини-проверка, практика, задание со звёздочкой и итог;
- итоговая диагностика и мини-контрольная для каждой главы;
- универсальный тренажёр по любой главе или всему курсу;
- интерактивные лаборатории: √x, квадратная функция/дискриминант, системы прямых,
  числовые промежутки, линейная функция, 1/x и 1/x²;
- общий прогресс по 51 теме и персональное повторение ошибок.

Содержание написано специально для курса и использует оглавление учебника как карту программы,
а не копирует текст учебника дословно.

## v1.2.0 — педагогическая шлифовка

Утверждённая оболочка v1.1 сохранена. Главы II–VI получили дополнительный педагогический слой во всех 42 темах:

- **«Картинка в голове»** — интуитивный смысл темы;
- **«Короткий маршрут решения»** — алгоритм до начала примеров;
- **«Разберём медленно»** — пошаговая раскрываемая памятка;
- **«Другой взгляд»** — альтернативный способ понять или проверить;
- **«Если застрял»** — конкретное действие, которое помогает продолжить;
- **«Поймай ошибку»** — интерактивный разбор типичной ошибки.

Цель версии — дать ученику возможность самостоятельно восстановить ход решения, а не только повторить готовый образец.
