отключённую до настройки взрослым инфраструктуру Cloud Brain:

- Google Parent Auth только в Adult Center;

## v1.5.0 — живой помощник «Kitsune»

В игровой дизайн добавлен собственный интерактивный SVG-персонаж курса — **Kitsune**.

### Что умеет Kitsune

- знает, какой урок и экран сейчас открыт;
- использует `remember`, `formula`, `summary`, `mistake` и простое объяснение именно текущей темы;
- даёт короткий контекстный совет по нажатию **«💡 Совет»**;
- кнопка **«🌱 Объясни проще»** переводит урок на самый простой уровень объяснения;
- реагирует на правильные и неправильные ответы;
- замечает серию правильных решений;
- после двух ошибок подряд предлагает замедлиться и проверяет типичную ошибку текущей темы;
- меняет поведение на контрольных, диагностике, экране ошибок и прогресса;
- реагирует на завершение урока;
- после бездействия переходит в спокойное «спящее» состояние;
- один раз в день приветствует ученика;
- умеет прочитать текущий совет вслух через системный `SpeechSynthesis`, если браузер его поддерживает.

### 9 анимационных состояний

`idle`, `wave`, `think`, `explain`, `happy`, `oops`, `focus`, `cheer/celebrate`, `sleep`.

Глаза Kitsune мягко следят за указателем мыши на компьютере.

### Режимы

В боковой панели и в настройках самого помощника доступны:

- **✨ Активный** — реакции, советы и поддержка по ходу обучения;
- **💡 Только советы** — без постоянных поздравлений; Kitsune вмешивается по запросу и при повторной ошибке;
- **🙈 Выкл.** — персонаж полностью скрыт.

Выбор сохраняется в `localStorage` (`a8_assistant_mode`).

**Классический дизайн не изменён:** Kitsune визуально показывается только в игровом режиме.


## v1.5.1 — эмоциональный голос Kitsune

Озвучка помощника переработана в отдельный голосовой профиль без копирования голоса какого-либо существующего персонажа.

### Голосовые профили
- **⚡ Живой** — основной: молодой, звонкий, энергичный и немного мультяшный;
- **🌿 Мягкий** — спокойнее для объяснений и поддержки;
- **📘 Чёткий** — медленнее и нейтральнее для учебного текста.

### Эмоции
Скорость и высота системного русского голоса меняются по состоянию Kitsune:
`wave`, `think`, `explain`, `happy`, `oops`, `focus`, `cheer`, `celebrate`, `sleep`.

### На телефоне
Курс получает список русских голосов, установленных в Android/iOS и браузере. При автовыборе предпочитается локальный русский голос, а при наличии подходящих вариантов — более яркий женский голос. Пользователь может выбрать любой доступный голос вручную.

### Настройки
В окне Kitsune → ⚙:
- включить/выключить голос;
- выбрать профиль;
- выбрать конкретный русский голос устройства;
- включить **автоозвучку**;
- нажать **«▶ Послушать Kitsune»**.

Автоозвучка по умолчанию выключена, чтобы курс не начинал неожиданно говорить. После её включения Kitsune сам озвучивает важные советы и короткие реакции. На мобильных устройствах первый звук запускается после пользовательского нажатия — это ограничение браузеров.

Если Web Speech API отсутствует, курс продолжает работать без озвучки.


## v1.6.0 — AI Tutor Lite

В Kitsune встроен локальный интеллектуальный математический тьютор, который работает **полностью в браузере, офлайн и без API**.

### Как он работает

Tutor Lite получает только локальный контекст курса:

- `lessonId` текущей темы;
- условие выбранного упражнения;
- введённый учеником ответ;
- допустимые правильные ответы;
- формулу, правило, блок `remember`, `why`, типичную ошибку и подсказку урока;
- накопленную локальную память ошибок ученика.

### Лестница помощи

Для каждого упражнения есть 4 уровня:

1. **💡 Намёк** — направление без раскрытия ответа;
2. **👣 Первый шаг** — с чего начать решение;
3. **🔎 Явная подсказка** — правило/формула и место, которое нужно проверить;
4. **📘 Полный разбор** — алгоритм и ожидаемый итог.

Кнопка **↺ Сначала** закрывает лестницу, чтобы попробовать задачу заново самостоятельно.

### «Почему?»

Tutor Lite использует объяснение смысла правила текущей темы, а не только сообщает алгоритм.

### «Проверь мой ход»

Можно написать промежуточные действия или итоговый ответ. Tutor Lite анализирует последний шаг и пытается определить класс ошибки.

### Распознаваемые типичные ошибки

Локальный движок различает, в частности:

- смену знака при делении неравенства на отрицательное число;
- потерю знака числа;
- ОДЗ и запрещённые значения;
- действия с рациональными дробями;
- квадратные корни;
- дискриминант и квадратные уравнения;
- теорему Виета;
- системы уравнений;
- интервалы и границы;
- свойства степеней;
- стандартный вид числа;
- область определения и свойства функций;
- арифметические ошибки;
- общий неверный ход решения.

### Память ошибок

Tutor Lite хранит статистику только локально в `localStorage`:

- `a8_tutor_memory_v16`;
- `a8_tutor_help_v16`.

Если одна ошибка повторяется, Kitsune сообщает об этом и делает следующую помощь проще. При нескольких затруднениях по теме первый уровень подсказки автоматически переходит к более простому объяснению урока.

Полный сброс курса очищает и эту память.

### Интерфейс

В каждом упражнении игрового дизайна появляется кнопка:

**🧠 Kitsune Tutor**

Также кнопка **🧠 Tutor Lite** доступна прямо в окне Kitsune.

Классический дизайн визуально не изменён.

### Архитектура

`GitHub Pages → PWA → курс → Tutor Lite → Kitsune → голос/анимации`

Никаких внешних запросов, API-ключей, серверов или платных сервисов.


## v1.6.1 — более живая озвучка Kitsune

Системный Web Speech остаётся полностью локальным и бесплатным, но теперь Kitsune не читает всю реплику одним монотонным `SpeechSynthesisUtterance`.

### Что изменено

- длинная реплика разбивается на короткие смысловые фразы;
- каждая фраза получает свою скорость и высоту тона;

## v1.7.0 — Neural Voice Kitsune

Kitsune получил второй голосовой движок: **локальный нейросетевой Piper TTS**.

### Режимы

- **✨ Нейро** — локальная нейросетевая генерация;
- **📱 Системный** — прежний Web Speech API;
- внутренний режим `auto` использует Neural Voice, если модель подготовлена, иначе автоматически оставляет системный fallback.

### Первый запуск

Нейромодель не включена в ZIP проекта. Это сделано специально: файл около **63 МБ**, а курс обычно обновляется через веб-интерфейс GitHub.

В настройках Kitsune нажмите:

**⬇ Скачать голос Kitsune (~63 МБ)**

После загрузки библиотека сохраняет модель в Origin Private File System браузера. Затем выполняется короткая пробная генерация, которая подготавливает ONNX/phonemizer runtime.

### Основа голоса

- Piper voice: `ru_RU-dmitri-medium`;
- quality: medium;
- sample rate: 22,050 Hz;
- модель Piper Voices;
- датасет, указанный в model card: CC0.

Это не копия голоса какого-либо мультяшного персонажа. Поверх нейроголоса курс применяет собственную лёгкую обработку.

### «Мультяшность»

Регулятор **🎬 Мультяшность 0–100%** управляет:

- небольшим изменением pitch/detune;
- playback rate;
- присутствием голоса в среднем диапазоне;
- яркостью верхних частот;
- динамической компрессией;
- эмоциональными пресетами Kitsune.

Настройки специально ограничены умеренным диапазоном, чтобы речь оставалась человеческой и разборчивой.

### Эмоции

Для состояний `wave`, `think`, `explain`, `happy`, `oops`, `focus`, `cheer`, `celebrate`, `sleep` используются разные скорость, detune и яркость.

### Offline

Архитектура:

`GitHub Pages → PWA → Piper runtime → модель в OPFS → Web Audio → Kitsune`

После первого успешного скачивания и пробного запуска:

- модель хранится локально в OPFS;
- jsDelivr runtime/WASM кэшируется Service Worker;
- основной PWA app shell кэшируется отдельно;
- большие model responses Hugging Face не дублируются в Cache Storage.

При любой ошибке Neural Voice автоматически откатывается на системную озвучку.

### Зависимость

Neural Voice лениво загружает браузерную библиотеку:

`@mintplex-labs/piper-tts-web@1.0.5`

Она используется только при скачивании/запуске Neural Voice. Обычный курс, Tutor Lite и системная озвучка не зависят от неё.

## v1.8.0 — Kitsune Brain

Главный персонаж курса полностью заменён: вместо Альфи теперь используется оригинальный лисёнок **Kitsune**.

### Новый характер интерфейса

Kitsune появляется возле конкретного упражнения как персонаж из комикса и разговаривает через речевое облачко. При ошибке обычная кнопка **«Проверить»** не открывает настройки помощника.

Комиксный блок показывает:
- где именно разошёлся ход решения;
- какой промежуточный шаг был верным;
- какую конкретную операцию нужно проверить дальше;
- наводящий вопрос без автоматического раскрытия ответа;
- реакцию на повторяющуюся ошибку.

### Гибридный мозг

Архитектура:

`Math Engine → verified facts → Kitsune Brain → comic bubble`

**Math Engine / Smart Tutor** остаётся источником математической истины.

Локальная LLM **не имеет права самостоятельно менять вычисления**. Ей передаются уже проверенные факты: тип ошибки, следующий корректный шаг, правило темы и повторяемость ошибки. Модель используется только для естественной русской формулировки и сократического диалога.

### Локальная модель

Kitsune Brain использует WebLLM и компактную модель:

`Qwen2.5-0.5B-Instruct-q4f16_1-MLC`

- inference выполняется в браузере через WebGPU;
- внешний inference API отсутствует;
- API-ключи отсутствуют;
- модель скачивается только после явного нажатия пользователя;
- после подготовки WebLLM использует локальный browser cache;
- при отсутствии WebGPU или ошибке модели автоматически работает Smart Tutor;
- WebLLM указывает для этой quantized-конфигурации около 945 МБ требуемой VRAM.

### Режимы

В настройках Kitsune:

- **🧠 Brain** — Math Engine + локальная LLM;
- **⚙ Smart Tutor** — только детерминированный математический движок;
- **💡 Только подсказки** — без автоматического inline-разбора после ошибки.

По умолчанию используется Smart Tutor. Никакая большая модель не скачивается автоматически.

### «Проверить мой шаг»

В комиксном разборе можно написать промежуточную строку, например:

`−4x≥−8`

или

`D=16`

Kitsune сравнивает её с проверенной цепочкой решения. Для поддерживаемых типов задач движок различает корректный промежуточный шаг, ошибочный знак неравенства, неверный дискриминант и другие типовые расхождения.

### Память

Kitsune ведёт отдельную локальную память повторяющихся ошибок:

`a8_kitsune_brain_memory`

Она используется для адаптации реплик и хранится только в браузере.

### Голос

Системная и Neural Voice озвучка сохранены, но весь видимый интерфейс теперь относится к **Kitsune**.

### Совместимость

Kitsune Brain проверяет:
- наличие WebGPU;
- возможность получить GPU adapter;
- приблизительный объём RAM через `navigator.deviceMemory`, если браузер его сообщает;
- доступное browser storage.

Если устройство слабое, курс не блокируется: используется Smart Tutor.


## v1.9.0 — Kitsune Voice Dialogue

Kitsune получил полноценное окно разговора: можно писать текст или говорить в микрофон.

### Цепочка

`🎙️ микрофон → локальный Whisper → 🧠 Kitsune Brain → Math Engine context → 💬 диалог → 🔊 голос Kitsune`

Аудио не отправляется в speech API нашего проекта. Запись декодируется в браузере, преобразуется в mono 16 кГц и передаётся локальной модели Whisper.

### Локальное распознавание речи

Используется:

- `@huggingface/transformers@4.2.0`;
- `onnx-community/whisper-tiny`;
- русский язык (`language: "russian"`);
- Web Worker, чтобы загрузка и inference меньше блокировали интерфейс.

Для WebGPU выбран профиль:
- encoder: `fp16`;
- merged decoder: `q4`.

Если WebGPU недоступен, используется более медленный WASM fallback с q8.

Модель не загружается автоматически. В настройках Kitsune есть отдельная кнопка:

**⬇ Подготовить Whisper**

### Push-to-talk + автоматическая пауза

Кнопка **🎙️ Говорить**:

1. запрашивает разрешение на микрофон;
2. начинает запись;
3. отслеживает уровень голоса;
4. после того как речь началась, пауза примерно 1,45 секунды автоматически завершает запись;
5. максимальная длина одной реплики — 20 секунд;
6. запись преобразуется в 16 кГц;
7. Whisper распознаёт её;
8. распознанный текст автоматически отправляется Kitsune.

Кнопку можно нажать повторно для ручной остановки.

### Текстовый разговор

Текстовый диалог доступен даже без Whisper. Enter отправляет сообщение, Shift+Enter создаёт новую строку.

Kitsune видит текущий урок и выбранное упражнение. Если активен Kitsune Brain, локальная LLM формулирует живой ответ. В Smart Tutor режиме используется детерминированный fallback на проверенные материалы урока.

### Математическая безопасность

Свободный диалог не превращает LLM в источник истины.

В Brain передаётся проверенный контекст:
- тема;
- условие текущего задания;
- правило урока;
- штатная подсказка;
- безопасные шаги Smart Tutor.

Если ученик не просил готовый ответ явно, финальный ответ не добавляется в контекст модели.

### Голосовой ответ

Опция **🔊 Голосовые ответы** включена по умолчанию.

После ответа Kitsune использует уже существующую систему озвучки:
- Neural Voice, если она доступна;
- системный голос — как fallback.

### История диалога

Последние сообщения хранятся локально в:

`a8_kitsune_dialog_history_v19`

На сервер курса история не отправляется.

### Где открывается

- в меню Kitsune появилась кнопка **💬 Поговорить**;
- внутри разбора задания появляется **🎙️ Сказать Kitsune**;
- на телефоне диалог открывается как нижняя полноэкранная карточка;
- на ПК — как большая компактная dialog-card.

### HTTPS

Доступ к микрофону требует secure context. На GitHub Pages HTTPS это выполняется. В однофайловом локальном preview остаётся текстовый диалог и выводится пояснение.

## v1.10.1 — Sprite Hotfix

Исправлена ошибка, при которой новая Kitsune могла сначала появиться, а после первой смены состояния исчезнуть, оставив пустой прямоугольник.

## v1.11.9 — PWA Auto Update

Приложение теперь достаточно установить один раз.

### Как работает обновление
- при запуске PWA регистрирует Service Worker с `updateViaCache: "none"`;
- вскоре после запуска выполняется принудительная проверка `registration.update()`;

- новый Service Worker активируется, приложение автоматически перезапускается;

- `⏳ Обновляю Kitsune…`.

Обновление приложения не очищает:
- учебный прогресс;
- ошибки;
- настройки;
- историю/локальную память Kitsune;
- localStorage/IndexedDB/OPFS;
- неизвестные CacheStorage-кэши сторонних AI runtime/model loaders.

Service Worker теперь удаляет только старые кэши самого курса (`algebra8-v...`) и устаревшие кэши его JS runtime.

## v1.12.2 — Persistent AI Restore

Исправлено поведение локальных AI-моделей после PWA-обновления на iPhone.

Раньше новая версия PWA перезагружала страницу, поэтому:
- модель Brain оставалась скачанной, но WebGPU engine исчезал из RAM;

## v1.12.3 — iPhone Voice Unlock Fix

Исправлена озвучка на iPhone/iPad PWA.

Причина:
- iOS может потерять user activation, если `speechSynthesis.speak()` запускается через timer после `cancel()`;
- Web Audio `AudioContext.resume()` может быть вызван слишком поздно — уже после асинхронной генерации Neural Voice.

Исправления:
- на iOS системный SpeechSynthesis запускается сразу в стеке пользовательского жеста;
- на первом tap/touch заранее создаётся и разблокируется AudioContext Neural Voice;
- выполняется тихий one-sample playback для устойчивого iOS audio unlock;
- при возвращении PWA на экран выполняется `speechSynthesis.resume()` / `AudioContext.resume()`;

- старый context сбрасывается, если его DOM-упражнение больше не существует;

  выдуманного ответа — Kitsune прямо сообщает границу локального режима.
