# Kitsune Algebra 8 · v2.3.0-beta.3.7

Интерактивный курс алгебры для 8 класса: уроки, тренажеры, графики, проверка решений и диалог с Kitsune. Рабочая база очистки — коммит `0eac7a6`.

## Текущая архитектура

- GitHub Pages публикует статическую PWA. Service Worker кэширует курс и ресурсы; локальные модели подготавливаются отдельно.
- Math Engine, Tutor и помощь по конкретному заданию работают локально. Общий разговор может идти через Qwen и Cloudflare Worker, в том числе при открытом уроке.
- Микрофон распознается локальным Whisper через kitsune-voice-v19.js и whisper-worker-v1116.js. neural-voice-v17.js и local-voice-lab-v231.js обеспечивают локальную озвучку; Piper Irina предпочтителен, существующие запасные варианты сохранены. Silero — дополнительная локальная настольная опция.
- voice-conversation-v237.js добавляет разговор без рук, прерывание озвучки, новую тему и память по контекстам уроков. Полный журнал хранится на устройстве; в Cloud может попасть отфильтрованная короткая выдержка (примерно до 920 символов) вместе с текстом текущего вопроса. Сырой звук не отправляется.
- Worker использует Qwen через серверный API. D1 KITSUNE_DB хранит минимальный реестр доступа: заявки, решения владельца и состояния доступа. Secrets остаются в Cloudflare.
- Owner/admin проверяются сервером. Сохраняются proof-of-possession устройства, восстановление Cloud-сессии и панель владельца.
- chat-dialog-firewall-v231.js загружается последним и защищает диалог от нежелательной навигации. Порядок скриптов является частью рабочей сборки.
- Аналитика отключена. Подключенного облачного TTS нет.

## Структура

- Корень: index.html, styles.css, manifest.json, sw.js, version.json, модули курса и клиентской инфраструктуры.
- assets/: иконки и персонаж.
- cloudflare-broker/: исходник Worker, конфигурация и существующие тесты.
- tools/silero-local/: необязательный локальный сервер Silero.
- docs/DEPLOY.md: актуальное развертывание.
- docs/cleanup/: отчет и проверка ссылок.
- docs/archive/: историческая документация; не инструкция для текущей версии.
