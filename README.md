# Kitsune Math — математика 7–11 классов, ОГЭ и ЕГЭ

<img src="assets/kitsune-math-icon-192-v310.png" width="144" height="144" alt="Kitsune Math — общий значок без номера класса">

**Версия 3.1.0-rc.2 · локальная учебная платформа с устанавливаемой PWA.**

[Открыть курс](https://qsqgjhngyt-maker.github.io/algebra8-course/) · [Релизы](https://github.com/qsqgjhngyt-maker/algebra8-course/releases) · [Руководство ученика](docs/USER_GUIDE.md) · [Полная карта тем](docs/CURRICULUM.md)

Kitsune Math объединяет школьную математику и подготовку к экзаменам в одном интерфейсе: выбирайте курс, изучайте теорию на подходящем уровне, разбирайте примеры, решайте задания и возвращайтесь к ошибкам. Лис Kitsune помогает ориентироваться в уроке. Основное обучение работает локально в браузере; облачный диалог Qwen — отдельная добровольная возможность.

## Содержание

| Направление | Полноценные темы |
|---|---:|
| 7 класс | 112 |
| 8 класс | 116 |
| 9 класс | 77 |
| 10 класс | 75 |
| 11 класс | 62 |
| ОГЭ | 37 |
| ЕГЭ, базовый уровень | 26 |
| ЕГЭ, профильный уровень | 46 |
| **Всего** | **551** |

Школьные направления включают алгебру, геометрию, вероятность и статистику. Алгебра 8 класса содержит 63 темы в 9 главах: 51 исторический ID сохранён и дополнен 12 темами. В текущем QA учебные материалы не переписывались. Подробные названия разделов, глав и всех 551 тем находятся в [карте курса](docs/CURRICULUM.md).

Есть 9 полных тренировочных вариантов — по три для ОГЭ, ЕГЭ базы и ЕГЭ профиля. ОГЭ: 25 заданий; база: 21; профиль: 19. Развёрнутые решения проверяются учеником по критериям: это **самопроверка**, а не экспертное оценивание экзаменационной работы.

## Что умеет приложение

- Библиотека восьми курсов и сохранение выбранного направления.
- Главная курса, карта, главы, уроки и предсказуемые переходы назад.
- Три уровня объяснения: «Совсем просто», «Как в школе», «Хочу понять глубже», а также спокойное чтение полной теории.
- Примеры, практика, подсказки, проверка ответов, тренажёр, итоги глав и повторение ошибок.
- Раздельный прогресс по курсам; переход между направлениями не смешивает их результаты.
- Math Lab и домашние задания, связанные с выбранным курсом; классический генератор алгебры 8 класса доступен отдельно.
- Помощь по контексту конкретного задания, ручная озвучка и голосовой диалог при доступных возможностях устройства.
- Офлайн-оболочка и учебные материалы после первой успешной сетевой установки.
- Обновление через уведомление: новая версия активируется после подтверждения пользователя.

## Начало работы

Откройте [опубликованную платформу](https://qsqgjhngyt-maker.github.io/algebra8-course/), выберите направление и нажмите «Продолжить обучение» либо откройте карту курса. Для использования на домашнем экране установите приложение средствами браузера. Первый сетевой запуск должен завершиться до ухода офлайн.

Для запуска на компьютере скачайте полный LOCAL-архив из Releases, распакуйте в отдельную папку, установите Python 3 и запустите `START_LAN.bat`. Адрес на компьютере — `http://127.0.0.1:8080/`. Через `file://` PWA не проверялась. [Подробности запуска и публикации](docs/DEPLOY.md).

## Qwen через API

Подключение реализовано: браузер → существующий Cloudflare Worker → совместимый с OpenAI API сервис Alibaba Cloud Model Studio. В текущей конфигурации используется `qwen3.7-plus`. Постоянный API-ключ не размещается в браузере или GitHub.

Для облачного диалога нужны интернет, согласие взрослого, авторизация/одобрение устройства и работающий сервер с действующим ключом. На 16 сентября 2026 года проверка сервера возвращала `ok`, `ready` и `registryReady`: `true`. Это **не** проверка оплачиваемого ответа модели от имени пользователя. [Настройка, ограничения и диагностика Qwen](docs/QWEN_API.md).

Офлайн-уроки не требуют Qwen. Тяжёлые AI-модели не входят в репозиторий и не загружаются автоматически при открытии курса.

## Данные и безопасность

Прогресс хранится в браузере. Другой профиль, браузер, устройство, домен или порт имеют отдельное хранилище. Автоматическая межустройственная синхронизация результатов не обещается. Не очищайте данные сайта ради обновления; копия папки приложения не заменяет резервную копию браузерных данных. [Безопасность и приватность](CHILD_SAFETY.md).

## Статус версии

Это **release candidate**, не заявление о безошибочности на любом телефоне. Основные маршруты, контент, прогресс, экзамены, ресурсы, PWA и жизненный цикл голоса проверяются автоматизированно. Реальные iPhone/Safari, установка на домашний экран и качество распознавания настоящего микрофона требуют отдельного аппаратного smoke-test. Учебные материалы не являются официальной продукцией ФИПИ; статус нормативных источников указан внутри платформы и не переопределяется этим релизом.

Репозиторий сохраняет имя `algebra8-course`, чтобы не менять опубликованный адрес, браузерное хранилище и настройки облачной авторизации. Теперь это объединённая платформа Kitsune Math.
