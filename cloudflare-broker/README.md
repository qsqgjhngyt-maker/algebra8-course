# Kitsune Hybrid Broker

Действующая самостоятельная точка входа — `src/index.js`, версия сервера `2.3.0-beta.3.7.2`. Этот номер не синхронизируется искусственно с версией учебного фронтенда. В публикации Kitsune Math 3.1.0-rc.2 поведение сервера не изменялось, отдельный деплой Worker не выполняется.

Worker обслуживает авторизацию, реестр доступа и текстовый Qwen-чат. Старые `src/chat.js`, `src/voice.js` не импортировались точкой входа и удалены. Их ранние тесты заменены тестами текущих доступных контрактов.

Проверка: `npm run check` (Node.js с Web Crypto, Fetch и node:test). Настоящие ключи не нужны; тест не подтверждает внешний ответ Alibaba Cloud.

**Не запускайте deploy без проверки D1 и секретов.** Конфигурация wrangler не содержит полной существующей привязки базы. [Подробная настройка](../docs/QWEN_API.md) · [развёртывание](../docs/DEPLOY.md).
