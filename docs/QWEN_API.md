# Qwen API: подключение и диагностика

## Что реализовано

Приложение уже содержит облачный канал Qwen. Его путь:

```text
Браузер с согласием и разрешённым устройством
  → Cloudflare Worker /v1/qwen/chat
  → временный токен Alibaba Cloud
  → OpenAI-compatible /chat/completions
  → проверенный и ограниченный текстовый ответ
```

Текущий публичный broker: `https://kitsune-hybrid-broker.akronikl.workers.dev`. Origin опубликованного сайта: `https://qsqgjhngyt-maker.github.io`. Модель в конфигурации: `qwen3.7-plus`, регион `ap-southeast-1`. Поддерживаемый формат подтверждается [документацией Alibaba Cloud Model Studio](https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope). Доступность конкретной модели, квоты и права зависят от аккаунта и workspace; документация не доказывает наличие оплаченного доступа.

## Что проверено в этой публикации

16 сентября 2026 года реальный GET `/v1/health` с разрешённым Origin вернул HTTP 200, `ok: true`, `ready: true`, `registryReady: true`, регион `ap-southeast-1`. Версия существующего Worker — `2.3.0-beta.3.7.2`; она не обязана совпадать с версией статического курса.

Это означает, что endpoint доступен и сообщает о необходимых настройках и D1-привязке. Health не выполняет запрос к модели: оплачиваемая генерация, доступность `qwen3.7-plus`, остаток квоты и конкретный сертификат вашего браузера не подтверждены этим запросом. В этой задаче не извлекались ключи Alibaba Cloud и не менялись данные реестра пользователей.

## Что нужно пользователю

1. Открыть именно опубликованный HTTPS-сайт: для LOCAL с другим Origin облако может быть запрещено.
2. Во взрослом разделе ознакомиться с передачей минимального текста и подтвердить согласие.
3. Выполнить предусмотренное Google-подтверждение и, если требуется, дождаться одобрения владельцем.
4. Проверить broker, затем нажать «Тест Qwen» с разрешённого устройства.
5. После успешного теста попробовать короткий нейтральный вопрос без личной информации.

Ключ API в поля урока, сообщения чата и исходники GitHub вставлять нельзя. Регистрация устройства и согласие на облако не включают межустройственную синхронизацию учебного прогресса.

## Серверная конфигурация

Публичные параметры: `ALLOWED_ORIGIN`, `GOOGLE_CLIENT_ID`, `QWEN_TEMP_TOKEN_URL`, `QWEN_API_BASE`, `QWEN_MODEL`, `QWEN_REGION`, `CHAT_ENABLED`, настройки времени challenge и существующие лимитеры.

Секреты хранятся только в Cloudflare: `DASHSCOPE_API_KEY`, `GRANT_SIGNING_SECRET`, `PARENT_GOOGLE_SUB`; при необходимости `ALLOWED_GOOGLE_EMAILS`. Не выводите значения в логи и не коммитьте их. Worker требует действующую привязку `KITSUNE_DB` для разрешений устройств.

`wrangler.jsonc` в репозитории **не содержит полной D1-конфигурации**: действующая привязка была задана отдельно. Не запускайте бездумно `wrangler deploy`: сначала сверяйте существующую базу и bindings в Cloudflare. Публикация курса не требует изменения работающего Worker, ключей, модели, Google client ID или реестра. В этой версии серверный исходник сохранён без изменения поведения.

## Что передаётся

Текст текущего сообщения и при необходимости ограниченный фрагмент контекста. Клиент и сервер фильтруют некоторые категории личных данных и нежелательные сообщения, но автоматический фильтр не является абсолютной защитой. Аудиораспознавание в штатной локальной схеме выполняется на устройстве; отправка текста в облако — отдельный канал.

Worker сообщает `conversationLogging: false`; это описание приложения, не обещание отсутствия любых технических журналов и обработки у Cloudflare/Alibaba Cloud. Для чувствительных сведений используйте локальное обучение без облака.

## Типичные причины отказа

| Симптом | Что проверить |
|---|---|
| `origin_not_allowed` | Открыт другой домен, localhost или другой origin. Не расширяйте CORS до `*` ради обхода. |
| `cloud_consent_required` | Нет согласия в нужной подсистеме облачного диалога. |
| `enrollment_required` / отказ устройства | Подтверждение, сертификат, одобрение доступа или обновление сессии. |
| `ready: false` | Не хватает обязательной серверной конфигурации. |
| `registryReady: false` | Нет D1-привязки; это отличается от наличия API-ключа. |
| Ошибка временного токена | Ключ, регион, workspace и endpoint выпуска токенов. |
| Ошибка/таймаут чата | Квота, доступность модели, сеть, лимиты сервиса или серверный таймаут. |
| Ошибка только офлайн | Qwen требует сеть; уроки и локальный движок продолжают работать. |

Действующий backend предназначен для текстового Qwen-чата. Наличие старых названий voice/tts в клиентских интерфейсах не означает, что текущий Worker предоставляет отдельный облачный TTS API. Локальный голосовой стек и Qwen-чат проверяются раздельно.
