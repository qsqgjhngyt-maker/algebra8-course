# Диагностика перед изменениями

База: коммит `0eac7a6`, рабочая версия `2.3.0-beta.3.7`. Проверена полная локальная копия репозитория. Первоначальный план локальной очистки. Результат повторно проверен перед публикацией в main; см. Проверка.md.

| Решение | Файлы и основание |
|---|---|
| Оставить | Все подключенные в index.html клиентские модули, порядок загрузки и ASSETS в sw.js. В том числе kitsune-voice-v19.js, neural-voice-v17.js, local-voice-lab-v231.js, voice-conversation-v237.js, оба Whisper worker и финальный firewall. Старый номер имени не означает неиспользуемый код. |
| Удалить после обработки документации | analytics-v111.js и character-voice-v230.js: отсутствуют подключения, импорты и внешние обращения к их уникальным API/событиям. Упоминания есть только в старом README и исторических документах. Перед удалением заменить эти упоминания ссылками на исходный коммит. |
| Архивировать | Старые корневые DEPLOY/AUDIT/STAGE, KITSUNE/NEURAL инструкции; README_КУДА_ЗАГРУЗИТЬ.txt и README_СИНХРОНИЗАЦИЯ.txt. Сохранить предыдущие README, CHILD_SAFETY и OFFLINE_ARCHITECTURE как исторические версии перед обновлением. |
| Обновить | README.md, cloudflare-broker/README.md, CHILD_SAFETY.md, OFFLINE_ARCHITECTURE.md, README_УСТАНОВКА.txt; создать единую docs/DEPLOY.md. Синхронизировать обозначение релиза Worker и package/package-lock с beta.3.7. |
| Очистить конфигурацию | Убрать VOICE_ENABLED, VOICE_DESIGN_ENABLED и DEVICE_CERT_TTL_SECONDS: текущий Worker их не читает. Реальный TTL читает SESSION_CERT_TTL_SECONDS с исходным значением по умолчанию; его не менять. QWEN_TEMP_TOKEN_URL оставить: используется. |
| Отложить | cloudflare-broker/src/chat.js и src/voice.js не импортируются текущим Worker, но используются tests/stage2.test.mjs. Удаление нарушит тестовые импорты. whisper-worker-v1114.js остается в ASSETS. tools/silero-local остается как поддерживаемая локальная опция. |

Версия приложения в index.html, sw.js и version.json уже согласована. Старые `?v=` у неизмененных ресурсов — ключи кэша; они согласованы между index.html и sw.js, массово обновлять их не нужно. Worker сообщает beta.3.6.2, заголовок — beta.3.5, package — alpha.1, README — alpha. Синхронизация Worker затронет только метаданные, не алгоритмы.

В wrangler.jsonc отсутствует d1_databases. Историческая инструкция подтверждает настройку KITSUNE_DB через Dashboard. Неизвестный database_id не выдумывать. Без сверки существующей привязки запускать wrangler deploy нельзя. Secrets, D1, публичные адреса, модель и лимитеры сохраняются.

Исходные тесты: 11, успешно 7, ошибок 4. broker.test ожидает отклонения дополнительного prompt, router.test ожидает локального ответа на общий вопрос при открытом задании, stage2.test запрещает любой числовой ответ и ожидает старый TTS endpoint. Это диагностические находки до очистки; исправление поведения вне текущего объема. Тесты сохраняются, результаты не скрываются.

Проверки после изменений: неизменность клиентских файлов и порядка загрузки; существование ресурсов ASSETS; отсутствие runtime-зависимостей удаленных модулей; синтаксис JavaScript; повтор исходных тестов с сопоставлением тех же ошибок; diff и неизменность D1/Secrets. Реальный браузерный голос, Google и D1 требуют отдельного прогона в работающей среде.
