# Kitsune Analytics

Начиная с **v1.12.0 внешняя аналитика полностью удалена из проекта**.

Удалено:
- внешнюю аналитику Cloud tracker;
- Website ID;
- custom analytics events;
- consent toggle;
- owner opt-out;
- DNT/GPC analytics logic;
- `внешний аналитический домен` из CSP.

Kitsune не отправляет:
- посещения;
- ответы;
- прогресс;
- тексты диалога;
- распознанную речь;
- аудио;
- сведения об устройстве в аналитические сервисы.

Сетевой доступ остаётся только там, где он нужен самому приложению:
- GitHub Pages — загрузка приложения;
- jsDelivr — runtime локального AI;
- Hugging Face / связанные model endpoints — загрузка локальных моделей.

После загрузки поддерживаемые AI-функции выполняются локально на устройстве.
