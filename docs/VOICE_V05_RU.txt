Kitsune Voice Engine v0.5 — подготовительная ветка

ВАЖНО: новая автономная генерация на Android/iOS/ПК ещё не реализована.
Документ VOICE_ONDEVICE_RU.txt описывает недостающую модель, данные,
выбранное направление и обязательную проверку произвольной фразы без сети.
Эта версия предназначена для сохранения результатов и проверки готовых
уроков, а не для замены действующего продакшена.

Исходный проект qsqgjhngyt-maker/algebra8-course сохранён, основа
30d1df32c06db937858b71bda3d1698128448053. Содержание 88 учебных файлов
сохранено побайтно, структура 551 темы и учебный прогресс не менялись.

Один голос
В активном интерфейсе этой ветки: включение/выключение, автоозвучка,
остановка, прослушивание утверждённого образца и сохранение WAV офлайн.
Нет старых голосов, их списков и ползунков. Старый код сохранён в Git
и tests/release/history/voice-legacy. Микрофон и память диалога сохранены.
Пустая или неизвестная запись не переключает озвучку на другой голос.

Учебные WAV
grade8_algebra_v05: 28 PCM16 mono 24 кГц WAV, 219,12 с, три реальные темы
1-1, 1-2, 1-3, текст KitsuneTheoryContent.voice. Технические проверки
пройдены; прослушивание ещё ожидается. Пять утверждённых WAV v0.4,
эталон и словарь ударений не изменены. Все 21 исходный файл проверяется.
Полная теория отличается от короткой реплики voice; неизвестные тексты
в этой подготовительной сборке показывают сообщение о недостающей модели.

Офлайн и остановка
WAV сохраняются отдельно в kitsune-voice-pack-pilot-v04 и
kitsune-voice-pack-grade8-algebra-v05. Проверяется SHA256. Сохраняются
все 33 WAV без запуска речи. Модельные кэши не удаляются.
Открытие настроек отменяет ожидающий автосовет и не прерывает текущую
речь. Во время речи/настроек автостарт пропускается. Выключение
автоозвучки останавливает текущую речь и ожидающий запуск; выбор сохраняется.

Пакетный генератор на ПК
  .\tools\voice-engine\Generate_Course.ps1 -Limit 3
  .\tools\voice-engine\Generate_Course.ps1 -Limit 0
Limit 0 — все 63 темы алгебры 8. Остальные 60 пока не сгенерированы.
Рабочее окружение Kitsune-Qwen-Voice, его эталон и модель только читаются.
Утверждённый словарь не меняется. Новые тексты подготавливаются отдельно,
формулы раскрываются, короткие фразы объединяются, исходные тексты сохраняются.
Повторный запуск использует записи по подписи параметров и SHA256.
Текущие 28 WAV уже повторно использованы без загрузки модели/изменения файлов.
Неудачный запуск не подключает неполный пакет. non_streaming_mode=True:
потоковый режим в пробах некоторых коротких фраз возвращал 0,16 с тишины.
Это создание пакетов на ПК, а не генератор на телефоне.

Проверка готовых уроков
  node tools/voice-engine/prepare-local-preview.cjs
  .local-preview\START.bat
ПК: http://127.0.0.1:8080/algebra8-course/
Телефоны той же сети: https://192.168.3.10:8443/algebra8-course/
Адрес сети при необходимости меняется через Start_Local.ps1 -LanAddress.
Для установки и офлайн на телефоне требуется доверенный HTTPS.
Закрыть старое окно сервера, запустить текущий START.bat, принять обновление.
Проверять обычные кнопки тем 1-1, 1-2, 1-3; автоозвучку и настройки во время
чтения; затем сохранённые уроки без сети. Новые произвольные фразы пока
не генерируются. Локальный сервер используется только для установки/проверки.
Исправление разбора даты сертификата не зависит от языка Windows; существующий
сертификат повторно используется. Доверие автоматически не устанавливается.

Проверки
  npm run voice:verify
  npm run test:voice-unit
  npm test
  node tests/release/qa-inventory.cjs
  <Python из .venv> tools/voice-engine/test_course_pronunciation_v05.py
Browser/телефонные проверки не подтверждены: соединения к localhost из среды
Codex запрещены. Автотесты поведения используют имитацию браузерных API;
они не подтверждают тембр/произношение и автономность на устройствах.
