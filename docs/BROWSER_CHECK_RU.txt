Браузерная проверка Kitsune Voice Engine и PWA перед публикацией

Текущая сборка прошла проверки исходников и моделей браузерных API.
Настоящий браузерный сценарий пока заблокирован политикой окружения:
ERR_NETWORK_ACCESS_DENIED при открытии localhost; автоматическая
проверка разрешений запрещает sandbox_approval. Это ограничение
исполнения, а не успешно пройденная проверка приложения.

Подготовленные сценарии
tests/release/qa-voice-pwa.cjs проверяет /algebra8-course/ с настоящим
service worker и Web Audio. Создаётся отдельный временный браузерный
профиль. Данные основного браузера не используются.
Проверяются настройки во время WAV, отсутствие параллельных записей,
перезагрузка без сети, математический Worker, сохранение автоозвучки
при мобильном размере экрана. При KITSUNE_PREVIOUS_ROOT дополнительно
проверяются неудачная установка, принятие обновления и откат с новым
именем кэша, сохранение прогресса, WAV и модельного кэша.
Мобильный размер экрана в Chromium не заменяет физический iPhone.

Запуск вне ограниченного окружения
Использовать Node.js 22 или новее. В распакованной новой версии:
  npm install --ignore-scripts
  $env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
При другом расположении браузера указать его фактический путь.
Если библиотека Playwright уже установлена отдельно, вместо установки
можно задать PLAYWRIGHT_MODULE полным путём к её каталогу.

Распаковать Kitsune_PreVoice_Base_30d1df3.zip в соседнюю папку
algebra8-before-voice. Это исходная версия до подготовленных коммитов.
В PowerShell из папки новой версии:
  $env:KITSUNE_PREVIOUS_ROOT = [IO.Path]::GetFullPath('..\algebra8-before-voice')
  npm run test:voice-pwa
Без KITSUNE_PREVIOUS_ROOT тестирует только текущую версию.
Полный успешный сценарий с предыдущей версией должен показать семь PASS,
включая отсутствие необработанных браузерных ошибок.
Результат сохраняется в tests/release/voice-pwa-results.json.

Дополнительная регрессия
  npm test
  npm run test:voice-unit
  npm run test:browser
  npm run test:upgrade
Последняя команда использует тот же KITSUNE_PREVIOUS_ROOT.
Стандартная установка создаст настоящий package-lock.json; прежний
ошибочно названный PNG сохранён в tests/release/history/legacy-preview.png.

Ручная проверка на Android и iPhone
Открыть тестовую PWA, включить автоозвучку, начать чтение и открыть
настройки. Чтение продолжает звучать одним голосом, настройки не
добавляют пробную реплику. Изменить голос/ползунки: проба запускается
только отдельной кнопкой. Выключить автоозвучку: речь останавливается.
Повторить после перезапуска. Проверить новый ручной запрос во время
чтения, кнопку остановки в теории, офлайн после загрузки всех WAV,
предложение обновления и его принятие, затем откат на тестовой копии.

Публикация
Публиковать после успешной браузерной и мобильной проверки, сверив
текущую основную ветку. Исходники брокера не менялись; отдельного
развёртывания сервера для этой сборки не требуется.
