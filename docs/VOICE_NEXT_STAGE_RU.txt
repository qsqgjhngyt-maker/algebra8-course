Следующий пакет голоса Kitsune: реальные уроки алгебры 8 класса

Исторический отчёт предыдущего этапа f4300995. Актуальный статус описан
в VOICE_V05_RU.txt и VOICE_ONDEVICE_RU.txt: созданы 28 новых учебных WAV,
старые голоса отключены в пробной ветке; автономный TTS ещё не реализован.
Ниже сохранено описание того, что было сделано до этих изменений.

Почему WAV слышны через локальную тестовую панель
Панель передаёт готовому движку ровно те пять пробных реплик, для которых
существуют утверждённые WAV v0.4. Обычная кнопка «Kitsune расскажет тему»
передаёт другой текст: поле voice текущего урока. Готовая запись используется
только при точном совпадении текста; для остальных реплик работает прежний
динамический / системный голос. Включение пробного пакета сохраняется, но
не добавляет отсутствующие записи. Статические WAV не синтезируют новую речь.

Проверено по текущим исходникам
В разделе grade8 / g8-ready содержатся 63 темы алгебры. Совпадений их
полных текстов voice с отдельными сегментами или полными последовательностями
pilot_v04: ноль. Связь штатной кнопки проверена в platform-v300.js:
platformSpeakTheory вызывает speakTheory(d), затем v151Speak(d.voice).
Это проверка исходников и сопоставления текстов. Остальные кнопки чтения
полной теории и ответы помощника используют другие тексты и требуют
отдельного покрытия; данный список не охватывает всю возможную речь.

Подготовленные материалы
tools/voice-engine/course-v05/lesson-candidates.json — все 63 исходных
текста с идентификаторами тем, названиями, привязкой к штатной кнопке,
контрольными суммами текста и файлов источников.
tools/voice-engine/course-v05/first-three-lessons.json — первые три темы:
1-1 Рациональные выражения.
1-2 Основное свойство дроби. Сокращение.
1-3 Сложение и вычитание дробей с одинаковыми знаменателями.
В этих файлах status=texts_only и playable=false. Они не подключены
к проигрывателю и не являются готовыми аудиопакетами.

Тексты перенесены из voice без редакторской замены. В них встречаются
формулы, латинские переменные и математические знаки. Перед генерацией
нужно отдельно подготовить spoken / prepared_text для корректного чтения
формул и ударений, сохранив исходный text для точного сопоставления с PWA.
Простое разбиение строки по точкам не гарантирует правильного чтения
формул и чисел. Архивный генератор v0.4 не адаптирован к этому списку:
нельзя подменять его исходный JSON или писать поверх pilot_v04.

Последовательность следующего этапа
1. Подготовить произношение трёх выбранных уроков и сегментацию без потери
   исходного текста. Словарь ударений подключить из сохранённой копии.
2. Создать отдельный новый пакет и отдельный каталог. Сохранить эталоны,
   настройки голоса и все старые WAV без перезаписи.
3. Проверить каждый WAV, контрольные суммы и восстановление текста из
   сегментов. Прослушать произношение формул и сравнить голос с эталоном.
4. После проверки подключить новый индекс к штатной озвучке и сохранять
   записи в отдельном офлайн-кэше. Кнопки чтения, остановки и автоозвучки
   должны обращаться к той же общей остановке речи.
5. Проверить именно три выбранных урока через штатную кнопку на ПК и
   телефонах. Другие темы пока продолжат читаться прежним голосом.
6. Расширять покрытие оставшихся тем отдельными проверенными пакетами.
Динамический TTS для произвольных ответов остаётся отдельным этапом.

Повторная проверка списка
  node tools/voice-engine/export-course-texts.cjs
Команда сверяет сохранённые списки с текущим curriculum и исходными
текстами. При изменении уроков сначала проверить изменения, затем:
  node tools/voice-engine/export-course-texts.cjs --write
Перезаписываются только списки-кандидаты course-v05; WAV и архивные
исходники v0.4 не затрагиваются.
