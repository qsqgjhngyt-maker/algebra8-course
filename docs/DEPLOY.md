# Развертывание beta.3.7 после очистки

## GitHub Pages

1. Применить очистку одним коммитом поверх 0eac7a6. Проверить diff; порядок скриптов, index.html, sw.js и version.json остаются прежними.
2. Опубликовать через существующую настройку GitHub Pages. Сохранить .nojekyll и весь набор рабочих JS/CSS/assets.
3. Открыть приложение онлайн и проверить отображение beta.3.7. Не очищать localStorage, IndexedDB, OPFS или модели Whisper/Piper.

## Cloudflare Worker

Очистка не требует развертывания Worker для работы клиента. Изменение VERSION в исходнике синхронизирует метаданные репозитория; работающий сервер может продолжать сообщать beta.3.6.2 до отдельной публикации.

В текущем wrangler.jsonc нет d1_databases. Привязка KITSUNE_DB ранее настроена через Dashboard. Этот файл пока не является полной конфигурацией для безопасного CLI-развертывания.

Перед будущим развертыванием сверить существующий Worker в Dashboard: KITSUNE_DB, точные database_name/database_id, Secrets, переменные и лимитеры. Внести в локальную конфигурацию только подтвержденную существующую привязку. Не создавать новую базу и не подставлять пример database_id. При обновлении исходника через Dashboard также сохранить существующие bindings и настройки.

Сохраняются DASHSCOPE_API_KEY, GRANT_SIGNING_SECRET, PARENT_GOOGLE_SUB и при наличии ALLOWED_GOOGLE_EMAILS. Не менять значения ключей, идентификатор владельца, D1 или данные реестра ради очистки.

VOICE_ENABLED, VOICE_DESIGN_ENABLED и DEVICE_CERT_TTL_SECONDS удалены из конфигурации репозитория как неиспользуемые. Реальный Worker читает SESSION_CERT_TTL_SECONDS (по умолчанию 604800) и DEVICE_REFRESH_GRACE_SECONDS (2592000); действующие значения и поведение не менялись. QWEN_TEMP_TOKEN_URL используется и сохранен.

## Проверка

Из cloudflare-broker выполнить:

```text
node --check src/index.js
node --test tests/*.test.mjs
```

Исходный npm run check запускает только broker.test.mjs; полный набор сейчас имеет 4 известные ошибки из 11. См. отчет очистки. Эти проверки не подтверждают работу реального D1 или Google.

После публикации проверить урок и точную математику, общий Cloud-диалог, помощь по заданию, owner/admin, заявку и одобрение, полное закрытие и повторное открытие PWA, сохранение Cloud-сессии, Whisper, подготовленную Irina, прерывание голоса, разговор без рук, новую тему, разделение памяти по урокам и отсутствие ухода диалога на главную. Проверить офлайн-урок с подготовленными моделями.

У /v1/health с разрешенным Origin проверить ok, ready и registryReady. Значение ready не заменяет registryReady. Не отправлять тестовые запросы одобрения/отзыва реальным пользователям.

## Откат

Отменить единый коммит очистки стандартным git revert и опубликовать прежние файлы через существующий процесс. Базу, Secrets и хранилища браузера откат не затрагивает.
