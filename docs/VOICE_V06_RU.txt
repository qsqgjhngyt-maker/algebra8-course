Kitsune Voice Engine v0.6.4 — шаги, результаты проверки и повторное чтение

Обновление v0.6.4:
— Разбор читает первый открытый шаг, затем каждый «Следующий шаг», объяснение
  «Почему так?», явно показанный ответ и результат «Проверить мой ход».
— Обычная «Проверить» читает фактический результат курса, в том числе ошибку.
  Самопроверка не называется автоматически проверенным верным решением.
— «Автоозвучка» управляет этими действиями и ответами чата. Настройка объявлена
  через глобальный let; чтение window.v151VoiceAuto раньше игнорировало её.
— В разборе добавлена «Прочитать шаг», под ответом разговора — «Прочитать».
  Ручное чтение доступно при отключённой автоозвучке; общий голос должен быть включён.
— Подготовка и ошибки видны рядом с разбором и результатом проверки. Прошедшее
  время обновляется каждые 15 секунд; это не оценка времени до окончания.
— Закрытое меню больше не блокирует чтение из-за оставшегося класса настроек.
  «Разобрать текущее» закрывает меню до запуска речи; без задания объясняет,
  как выбрать его. Отложенная очистка не отменяет активную подготовку/чтение.
— Учебное действие заменяет предыдущую речь, фоновые советы её не прерывают.
  Поздний ответ Brain не запускает вторую озвучку. Начатый разговор забирает
  управление: закрытие старого разбора не останавливает его реплику.

Новые записи генератора сохраняются отдельно в CacheStorage после получения
звука, даже если браузер заблокировал воспроизведение. Для той же подготовленной
фразы повтор и перезапуск PWA используют сохранённый WAV без Worker/сети.
Повторное нажатие во время первой подготовки той же фразы продолжает работу,
а не запускает её заново. Другая фраза отменяет прежнюю задачу. Кэш ограничен
64 последними частями речи; старые утверждённые WAV и модели не удаляются.
Браузер может освобождать локальные данные: кэш не заменяет исходные пакеты.

Идентичность кэша: fingerprint файлов модели/runtime, SHA утверждённого
reference, SHA подготовленного текста, версия синтеза SYNTHESIS='v06-1'.
Перед чтением сверяются метаданные и SHA-256 сохранённого WAV. Повреждение
или другой reference ведут к удалению только этой записи и новой генерации.
При изменении алгоритма Worker/Core, влияющем на звучание, нужно повысить
SYNTHESIS в dynamic-voice-v05.js. Кэш имеет собственный префикс
kitsune-generated-voice-v06- и переживает обновления текущей оболочки.
Сохранённый звук содержит произнесённый текст; данные остаются на устройстве.

Ограничение остаётся: первая неизвестная фраза на проверенном WASM заняла
около 218 секунд для 4,3 секунды звука. Повторное чтение быстрее за счёт кэша;
первичная генерация не ускорена этим обновлением. Это кандидат для испытаний,
а не подтверждённый быстрый разговорный движок для Android/iOS/ПК.
Модель, runtime, Worker/Core, утверждённые WAV и словарь не изменены.
Ни тембр генератора, ни работа на настоящих телефонах пока не утверждены.
Откат именно v0.6.4 — предшествующий коммит df6168e; при выпуске нужен новый
build/cache оболочки. Старые пакеты и прогресс сохраняются.

Ранее исправлено в v0.6.3:

Исправлен воспроизведённый сбой: загруженный модуль разговора наблюдал изменения
всего интерфейса и останавливал любое чтение при закрытом разговоре. Теперь
отмена срабатывает при закрытии разговора и только для начатой в нём реплики.
Освобождение микрофона также сохраняет состояние продолжающегося чтения урока.

В разговоре показываются подготовка генератора и ошибки. Общая «Автоозвучка»
управляет советами и ответами; старый отдельный переключатель голосовых ответов
удалён, его сохранённый флаг больше не подавляет речь. Существующий общий выбор
пользователя сохраняется. При выключенной автоозвучке ответы остаются текстовыми.
При ошибке генерации разговор без рук не запускает микрофон как после успешного
чтения. После голосового обращения микрофон ждёт реального окончания приветствия;
прежний таймер 2,4 секунды больше не обрывает подготовку длинной новой фразы.

Проверки этих переходов выполняют настоящий код контроллеров с имитацией DOM,
плеера и микрофона. Они не заменяют проверку слышимого звука на устройствах.

Теперь существуют реальные переносимые модели, а не заглушка trySpeak=false.
Из локально установленного Chatterbox Multilingual 0.1.7 получен один голос
по утверждённому WAV Kitsune. Это перенос голоса через образец, не обучение
новой модели на 33 записях. Тембр может отличаться от прежнего Qwen и требует
прослушивания. Одобрение нового тембра пока не получено.

21 сохранённый исходный файл, прежние WAV и словарь ударений не изменены.
88 исходных файлов уроков не изменены. Готовые записи остаются первым выбором
при точном совпадении текста. Неизвестная фраза после установки генератора
создаётся на устройстве. Системный голос, Irina, Dmitri и сервер на ПК
не подставляются при ошибке.

Пакет модели: 579 048 010 байт, около 552 МБ в двоичных единицах.
Отдельный кодировщик нового голоса на устройстве не нужен: параметры нашего
голоса вычислены заранее. Языковая модель и линейные веса акустики сжаты
до четырёх бит; таблицы входов — до восьми бит. Свёртки сохранены FP32.
Файлы весов разделены на части до 32 МБ. Модель и runtime не входят в
автоматическую установку PWA; скачиваются только по явной кнопке.

Подтверждено: новая фраза сгенерирована переносимыми ONNX на CPU ПК,
без PyTorch-модели, CUDA или сетевых запросов. Для фразы «Привет! Я Китсуне.
Давай решим новую задачу вместе.» получено 11,64 секунды речи за 53,12 секунды.
Это не замер WebAssembly. Проверены реальные динамические формы акустического
графа для 17, 49 и 291 токена; замена комплексного FFT проверена численно.
Тесты управления чтением используют имитацию браузерных API и не доказывают
скорость, качество или доступный объём памяти настоящего телефона.

Подтверждён запуск настоящего ONNX Runtime Web 1.22.0 / WebAssembly на Node V8:
4,32 секунды звука за 217,66 секунды, запросы сети при синтезе запрещены.
Это проверка вычислительного WASM и логики worker, а не браузера: Blob-загрузка
модуля, браузерный CacheStorage, Web Audio и перезапуск PWA ещё требуют проверки.
Это отдельные прогоны стохастической модели;
совпадение произнесённого текста и качество речи автоматически не подтверждены.
Отчёт: Kitsune_v06_Probe/wasm_v8_validation.json в каталоге outputs.

Ещё не подтверждены: прослушивание экспортированного голоса, браузер ПК,
автономная генерация в Android/iOS, длительная работа и расход памяти.
Статус manifest.json — candidate_needs_device_validation. Пользователь скачал
настоящий npm-архив, установщик исправлен и успешно извлёк его локально.
Runtime уже включён в новую локальную сборку; Python на устройствах не нужен.
Генерация медленная: пригодность для автоозвучки уроков пока не доказана.

Локальная проверка:
1. В папке Kitsune_Local_Server закройте прежнее окно сервера.
2. Запустите START.bat: runtime уже сохранён. INSTALL_GENERATOR.bat проверяет
   сохранённые файлы; повторная загрузка не нужна. При восстановлении получает npm-пакет
   onnxruntime-web@1.22.0 без выполнения установочных скриптов, сверяет SHA-512,
   извлекает только необходимые локальные файлы и запускает START.bat.
   Пакет npm не содержит package/LICENSE, поэтому текст Microsoft MIT входит
   в комплект установщика. Проверка версии, лицензии и контрольных сумм сохранена.
3. На ПК откройте http://127.0.0.1:8080/algebra8-course/ и примите обновление PWA.
4. В обычных настройках Kitsune нажмите «Сохранить генератор · около 600 МБ».
   Дождитесь 100%. Первое чтение может занимать существенное время.
5. Нажмите «Послушать Kitsune»: это всегда утверждённый WAV, даже после
   сохранения генератора. Звук запускается после обычной загрузки записи.
   Для генерации нажмите отдельную кнопку «Создать новую фразу» и подождите.
   Она доступна после сохранения генератора. Индикатор речи включается
   только при запуске аудио, а подготовка показывается надписью в настройках.
6. Для телефона нужен доверенный HTTPS-адрес ПК в той же сети. Используйте
   адрес, который показывает START.bat; 127.0.0.1 на телефоне не ведёт к ПК.
7. Сохраните генератор именно в установленной PWA, затем выключите сервер
   и сеть. Прочитайте новую фразу. Повторите после закрытия и открытия PWA.
8. Во время генерации и чтения откройте настройки, выключите автоозвучку,
   остановите чтение и запустите другую фразу. Одновременного звука быть не должно.
9. После загрузки большого меню снова нажмите «Послушать Kitsune» — запись
   должна звучать целиком. Откройте «Поговорить», отправьте один вопрос
   и дождитесь генерации: её этап виден в разговоре. При выключенной
   автоозвучке генерация ответа не запускается. После закрытия разговора
   повторите чтение записи. Прогресс обучения и установленный голос не очищайте.

Особенности реализации:
dynamic-voice-v05.js теперь управляет установкой, Web Audio и отдельным worker.
ondevice-voice-worker-v06.js использует только локальный проверенный кэш.
Во время синтеза fetch к серверу/CDN запрещён. На GitHub Pages используется
один поток WASM: специальные заголовки изоляции страницы не требуются.
Вычислительные сессии освобождаются по этапам; отмена уничтожает worker.
Подготовка показывает этап. При сообщениях о прогрессе ожидание продлевается,
но одна часть речи ограничена 20 минутами, а отсутствие прогресса — 5 минутами.
Сообщение о сбое сохраняется после завершения задачи и обновления интерфейса.
При выключенном голосе проба объясняет, где его включить. Видимая настройка
голоса управляет также прежним внутренним флагом готовых записей; включение
автоозвучки не прерывает уже звучащую запись, если голос был включён.
Поздний ответ старого чтения не проигрывается. Текст обрабатывается небольшими
частями; словарь ударений сохранён, формулы преобразуются в русские слова.
Кэши генератора имеют отдельный префикс и переживают обновление оболочки.
При прерывании установки старый установленный пакет остаётся выбранным.

Исходники и веса подготовлены локально. GitHub Pages не публиковался.
Откат: исходная подготовительная версия — коммит
386d44c4030912f432239beb44f3d53867f135b7. Для публикации отката нужно выпустить

браузера, версии ОС, скорости, работы без сети и результата прослушивания.
