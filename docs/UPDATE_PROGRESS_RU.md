# Обновление и сохранение учебного прогресса

Обновление выполняется на прежнем адресе GitHub Pages и в существующей установленной PWA. manifest.json сохранён побайтно: id, scope и start_url остаются ./.

Хранилище прогресса и перенос результатов алгебры 8 класса сохраняют прежние ключи. grade8-progress-bridge-v311.js, migration-v302.js и app.js совпадают с базой GitHub 30d1df32c06db937858b71bda3d1698128448053. Учебные идентификаторы не перенумерованы.

| Данные устройства | Поведение при обновлении |
| --- | --- |
| Пройденные темы, решённые задания, попытки и верные ответы | Сохраняются в существующих ключах прогресса каждого курса |
| Ошибки, текущий урок и серия занятий | Сохраняются |
| Старые a8_* результаты | Сохраняются; перенос в Grade 8 выполняется идемпотентно |
| Голос и автоозвучка | Выбранные значения сохраняются |
| Текст читалки и закладки v0.7.4 | Сохраняются в kitsune-reader-v074 |
| Статические записи WAV, пакет Piper, созданные фразы | Их отдельные кэши не удаляются активацией новой оболочки |

Service worker сначала сохраняет все обязательные ресурсы новой оболочки в отдельном кэше. Он не вызывает skipWaiting при установке. Пользователь принимает обновление кнопкой «Обновить сейчас»; при ошибке установки удаляется только новый неполный кэш. Активация удаляет прежние кэши оболочки и её общего runtime, сохраняя модельные и речевые кэши. localStorage и IndexedDB не очищаются.

107 автоматических тестов включают повторное открытие с сохранёнными результатами нескольких курсов, отсутствие двойного учёта старых попыток, сохранение закладок и настроек, отмену поздней речи, неудачную установку, сохранение Piper-кэшей и откат. 13 проверок приложения подтверждают сохранность 88 учебных файлов и целостность 551 темы.

Новая изолированная браузерная проверка RC5 → RC6 не завершена: проверочный браузер не смог подключиться к отдельному локальному серверу. Её нужно завершить перед реальной публикацией. Прежние успешные проверки браузера v0.7.4 и подтверждение пользователя на телефонах сохранены отдельно; они не выдаются за этот тест перехода.

На устройстве достаточно принять штатное обновление. Удалять PWA, очищать данные сайта или повторно доверять сертификату ради GitHub Pages не требуется. Другой домен, браузерный профиль или порт создаёт отдельное хранилище; это не перенос существующего прогресса. Очистка данных пользователем и удаление хранилища браузером находятся вне механизма обновления.

Для отката публикуется обратный Git-коммит с новым уникальным именем кэша оболочки. Учебное хранилище и кэши голоса остаются на устройствах. История локальных экспериментальных сборок и прежние архивы сохранены.
