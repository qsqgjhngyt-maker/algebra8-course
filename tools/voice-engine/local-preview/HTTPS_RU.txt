Kitsune — HTTPS для локальной проверки

На ПК можно продолжать проверку по прежнему адресу
http://127.0.0.1:8080/algebra8-course/.
Для телефона используется https://АДРЕС-ПК:8443/algebra8-course/.
Точный адрес и ссылку на сертификат показывает START.bat.
HTTPS работает на порту 8443; порт 8080 предназначен для HTTP.

Если браузер сообщает о недоверенном сертификате
(NET::ERR_CERT_AUTHORITY_INVALID), требуется вручную добавить доверие
именно к сертификату «Kitsune Local Test CA» этого локального комплекта.
Просто скачать файл недостаточно. START.bat не устанавливает доверие.
Файл: .local-state/kitsune-local-ca.cer рядом с START.bat.
На телефон скачайте его по HTTP-ссылке, которую показывает сервер:
http://АДРЕС-ПК:8080/__kitsune/certificate.cer.
Сверьте имя и SHA-256 с показанными в окне сервера.

Windows — Яндекс Браузер, Chrome, Edge:
1. Откройте kitsune-local-ca.cer → «Установить сертификат».
2. Выберите «Текущий пользователь».
3. «Поместить все сертификаты в следующее хранилище» → «Обзор» →
   «Доверенные корневые центры сертификации».
4. Завершите мастер и подтвердите добавление только Kitsune Local Test CA.
5. Полностью закройте браузер и откройте HTTPS-адрес из START.bat.
Другой профиль Windows или браузер с отдельным хранилищем требует
своей настройки доверия. В Firefox её нужно проверить отдельно.

iPhone/iPad:
1. В Safari скачайте сертификат по HTTP-ссылке сервера.
2. В настройках установите загруженный профиль с Kitsune Local Test CA
   (раздел «Основные» → «VPN и управление устройством» / «Профиль загружен»).
3. «Основные» → «Об этом устройстве» → «Доверие сертификатам» →
   включите полное доверие именно для Kitsune Local Test CA.
4. Вернитесь в Safari и откройте HTTPS-адрес из START.bat.
Установка профиля сама по себе не включает доверие для HTTPS.

Android:
1. Скачайте сертификат по HTTP-ссылке сервера.
2. В поиске настроек найдите «Установить сертификат».
3. Выберите сертификат центра сертификации (CA) и скачанный .cer.
   Названия разделов зависят от производителя и версии Android;
   сертификат Wi-Fi и пользовательский сертификат — другие назначения.
4. Подтвердите установку Kitsune Local Test CA и снова откройте HTTPS-адрес.
На управляемом телефоне установку может запрещать политика организации.

Если это другая ошибка:
ERR_SSL_PROTOCOL_ERROR — проверьте HTTPS-порт 8443.
ERR_CERT_COMMON_NAME_INVALID — используйте точный адрес из START.bat.
ERR_CERT_DATE_INVALID — проверьте часы и срок действия сертификата.
ERR_CONNECTION_REFUSED / TIMED_OUT — проверьте запущенный сервер,
одинаковую домашнюю сеть и открытие HTTP-ссылки на сертификат с телефона.
Если HTTP-ссылка тоже недоступна, доверие к сертификату ещё не решит
проблему подключения. Нужен точный код ошибки для следующей проверки.

Этот сертификат выдаётся на 7 дней. При смене адреса ПК или истечении срока
START.bat создаст новый: на устройствах потребуется доверить новый CA.
После завершения проверки можно удалить только добавленный Kitsune Local
Test CA из пользовательских сертификатов/профилей. Защиту браузера не отключайте.
Прогресс, генератор и WAV не очищайте: разные адреса HTTP/HTTPS имеют
отдельные данные приложения, это не означает удаление прежних данных.
