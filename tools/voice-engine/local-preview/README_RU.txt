Kitsune v0.6.4 — озвучка шагов и результатов проверки

На этом ПК локальная сборка обновлена. Перезагрузите страницу и примите
«Обновить сейчас». Повторная установка генератора и очистка данных не нужны.
Включите общий голос и «Автоозвучка». В обычном уроке нажмите «Разобрать
с Kitsune», затем «Следующий шаг». Проверьте верный и неверный ответ:
Китсуне читает текст результата курса. При ошибке автоматический разбор
не должен отменять начатую озвучку результата. Сам ответ читается после
нажатия «Показать ответ». Рядом с заданием видны подготовка и ошибка.

Выключите «Автоозвучка»: эти действия должны оставаться текстовыми.
В разборе есть «Прочитать шаг», под ответами разговора — «Прочитать».
Новая фраза при первом чтении готовится несколько минут. Дождитесь одного
ответа; повторное нажатие той же фразы больше не начинает работу заново.
После получения звука он сохраняется на устройстве (до 64 частей речи).
Повторите чтение без сети и после перезапуска PWA: готовая фраза использует
локальную запись. Другой новый текст всё ещё требует медленной генерации.
Автономная работа и звук на настоящих Android/iOS/ПК ещё требуют испытаний.

Сохранено из v0.6.3:

Исправлена отмена обычного чтения загруженным модулем разговора. Подготовка
генератора и ошибки теперь видны также в самом разговоре. Общая «Автоозвучка»
управляет ответами, отдельного старого переключателя голосовых ответов больше нет.
Записи, модель, прогресс и настройки не нужно удалять или устанавливать заново.

Реальные файлы модели подготовлены и сгенерировали новую фразу на CPU ПК.
Запуск в браузере и на Android/iOS ещё предстоит проверить. Тембр кандидата
может отличаться от утверждённого Qwen. Прежние WAV и словарь сохранены.
Действующая GitHub Pages PWA не опубликована и не изменена.

1. Закройте прежнее окно сервера. Запустите START.bat.
   ONNX Runtime Web 1.22.0 уже сохранён и проверен: скачивать его снова не нужно.
   INSTALL_GENERATOR.bat оставлен для проверки/восстановления компонента.
   Ошибка отсутствующего package/LICENSE исправлена, лицензия входит в комплект.
   Для сервера нужны Node.js 22+ и PowerShell 7. Python не нужен.
2. ПК: http://127.0.0.1:8080/algebra8-course/
   Телефон: защищённый адрес ПК, который показывает окно START.bat.
   Сейчас ожидается https://192.168.3.10:8443/algebra8-course/
   127.0.0.1 на телефоне означает сам телефон.
3. Для HTTPS вручную установите тестовый сертификат с адреса
   http://192.168.3.10:8080/__kitsune/certificate.cer
   Сертификаты и доверие автоматически не устанавливаются.
   Если браузер блокирует HTTPS, откройте HTTPS_RU.txt: там описано доверие
   для Windows, Android и iOS. Скачивания сертификата недостаточно;
   iOS требует также отдельно включить полное доверие после установки профиля.
4. Примите обновление PWA. Оформление и учебный раздел должны загрузиться.
   Откройте обычные настройки Китсуне и нажмите «Сохранить генератор».
   Нужно около 600 МБ места, загрузка выполняется один раз на каждом устройстве.
5. Нажмите «Послушать Kitsune». Эта кнопка всегда проигрывает утверждённую
   готовую запись. После установки генератора её назначение не меняется.
   Для новой фразы есть отдельная кнопка «Создать новую фразу».
   Во время подготовки новой
   фразы подождите: настоящий WASM на Node V8 создал 4,3 секунды звука за 218 секунд.
   Браузер и телефоны могут работать с другой скоростью. В настройках виден этап
   подготовки. Чтение можно остановить сразу; с сообщениями о прогрессе одна
   часть ждёт максимум 20 минут, без прогресса — 5 минут.
   Индикатор речи включается только после запуска звука. При подготовке
   показывается надпись. Ошибка остаётся видимой в настройках после остановки.
6. Во время чтения откройте настройки: дополнительная реплика не должна
   запускаться. Выключите автоозвучку, остановите чтение и начните другое.
   Выбор автоозвучки должен сохраниться после перезапуска приложения.
   После появления большого меню снова нажмите «Послушать Kitsune».
   Откройте «Поговорить», отправьте один вопрос и дождитесь подготовки,
   которая теперь показывается внутри разговора. Новая фраза может готовиться
   несколько минут. После закрытия разговора повторите пробу записи.
7. Сохраните генератор именно в установленной PWA. Выключите сеть и сервер
   ПК, перезапустите PWA и прочитайте новую фразу. Повторите на Android, iOS и ПК.
   Это обязательная реальная проверка; автоматического подтверждения здесь нет.

Готовые записи можно сохранить отдельно кнопкой «Сохранить голос офлайн».
Темы 1-1, 1-2, 1-3 используют прежний пакет из 28 записей. Статические записи
имеют приоритет при точном совпадении текста. Дополнительные старые голоса
при ошибке не включаются. Настройки и обычные кнопки используют один путь.

Подробное описание и откат: VOICE_V06_RU.txt в основном каталоге outputs.
Если видны только базовые кнопки: проверьте /algebra8-course/, перезапуск
сервера и принятое обновление. Панель загрузки CSS/JS:
http://127.0.0.1:8080/__kitsune/check/
На iOS Safari и установленная PWA могут иметь разные локальные данные.
